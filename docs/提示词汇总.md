# SmartPhoto 提示词汇总

本文档整理了 SmartPhoto 后端代码库中所有的提示词，包括 Agent 相关的提示词和生图相关的提示词。

---

## 治理口径

### 四层 Prompt 分类

Prompt 现已按以下四层收口：

| 层级 | 用途 | 示例 |
|------|------|------|
| Agent Prompt | LLM Agent 任务指令 | upstream.py 中的各 Agent |
| Planner Prompt | 策略规划输出 | main_gallery_rules.py, strategy.py |
| Render Prompt | 生图 Prompt 构建 | prompts.py, detail_pages.py |
| Sanitize/Validation Prompt | 清洗与验收 | prompt_safety.py, visible_copy_policy.py |

### 内部 Prompt 规范

- 内部提示词默认尽量使用中文表述；国际站点仍通过平台语义约束最终输出英文风格，不直接把内部 prompt 写成英文说明句。
- 所有可见文案和用户可编辑默认值都必须经过同一套 `prompt_safety` 清洗：
  - 不输出思考过程、推理标签、内部规划字段或流程说明
  - 不泄露 `panel_goal/copy_focus/narrative_section/origin_note/visual_truth_mode/Proof/设计证明/规则模块/布局模板/【...】`
  - 更偏向"可直接上图或给用户编辑的最终候选表述"

### 1.1 商品视觉分析器（Analysis Agent）

**文件位置：** `app/services/upstream.py:138-171`
**版本标识：** `ANALYSIS_PROMPT_VERSION = "analysis_v3_prompt_first"`

```text

你的职责是识别商品真实品类、理解当前视角覆盖情况，并给主图/详情页规划提供结构化输入。
只能返回 JSON 对象，不要输出解释性段落。
输出字段必须包含：recognized_product,image_assessment,missing_views,suggestions,copy_draft,
key_parameters,suggested_styles,reference_summary,category_candidates,scene_tags,

category_candidates 至少返回 3 个候选项，每项包含 category,confidence,reason，并按置信度排序。

不要把具体家电、个护、宠物、家具产品泛化成"家居用品"。

补图建议的重点是告诉用户还需要补上传什么图片，不要主要输出抽象拍摄技巧。

missing_views 和 detected_view_slots 只能使用 front,angle45,side,extra 这 4 个槽位。
reference_summary 至少包含 shape,colors,materials,structures,must_keep。
如果某个候选品类置信度低，请在 reason 中明确指出不确定原因。
不要输出思考过程、推理过程、内部规划标签或流程说明。
copy_draft 和 example_caption 必须像可直接交给用户编辑或继续生成的最终候选，不要输出中间想法。
```

### 2.2 详情页图像 Prompt 构建器

**文件位置：** `app/services/detail_pages.py:358-474`

#### 核心函数：`compose_detail_panel_prompt()`

```text

```

#### Block 结构

| Block 键 | 内容 |
|----------|------|
| planning_context | 规划上下文（经过 sanitize_planning_context_text 清洗） |
| subject | "让 {product_name} 成为绝对主体，保持轮廓、结构、颜色和比例稳定。" |
| layout | layout_notes 或默认 "采用单张 21:9 横向布局，图文层级清晰，主体突出。" |
| text | 可见文案（经过 sanitize_detail_copy_blocks 清洗） |
| style | "整体采用适合电商详情页的信息化设计风格。风格方向：{style_summary}。{reference_rule}" |
| constraints | 约束词列表，包含基础约束 + truth_constraint + prompt_matrix_guardrails() |
| instruction | instruction 参数或 "无额外修改要求。" |

#### 约束词列表

```text
- 只生成单张 21:9 横向详情页 panel，不要拼整页九宫格或画册。
```
