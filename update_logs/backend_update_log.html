本轮四大升级

PIPELINE REFACTOR

生成链路完成一次工程化拆分，稳定性与可维护性同步提升

原本耦合较重的 pipeline 被拆分为 copy 解析、prompt 流水线、规则解析、调度、持久化、渲染、质检等多个清晰模块。 这意味着复杂生成逻辑被整理为更清楚的后端骨架，后续扩展与维护都会更加从容。

  • 主图与详情页 prompt 构建改为标准化流水线，生成逻辑更可控。
  • copy 来源和兜底关系显式化，后续排查“这句文案从哪来”更容易。
  • 平台规则、槽位规则、详情页 panel 规则统一收束，便于持续扩展。
  • preview hash 和 contract 校验同步补齐，减少重复构建和隐性脏数据。
BRAND MEMORY PHASE 1

品牌记忆一期落地，系统开始具备“沉淀品牌资产”的能力

本轮正式搭建了品牌记忆的数据层、后台管理层和生成接入层。优质生成结果不再只是一次性产物，而是可以回流为品牌资产， 参与后续策略预览与风格注入，让系统逐步形成面向品牌的持续积累能力。

  • 新增品牌、品牌画像、品牌记忆条目、证据链等模型与迁移。
  • 新增后台品牌 CRUD、档案编辑、记忆条目查看与 evidence 追踪接口。
  • 新增业务侧 `GET /api/v2/brands`，前台可直接消费品牌列表。
  • 通过质量门的优质资产可自动沉淀为品牌记忆，形成业务闭环。
DELIVERY & OPS

发布、预检、回滚体系补齐，交付流程进一步标准化

除了业务功能，本轮也同步补齐了一套更成熟的工程化交付能力。开发、打包、预检、发布、回滚都有了更明确的脚本入口和流程约束， 整体上线维护路径更清晰，也更适合后续持续交付。

  • 新增 PowerShell 版开发、打包、预检、部署、回滚脚本。
  • 发布前可对环境和数据库关键状态做检查，减少人为失误。
  • 出现异常时可以更快速回退，不必依赖临场手工排障。
QUALITY & AUDIT

质量审核、历史审计、测试体系同步增强，可靠性进一步夯实

这轮更新并非只关注功能交付，也同步补强了大量可靠性建设。异步质量审核与品牌沉淀打通，Stage H 历史审计脚本补齐， 同时新增了一批覆盖核心链路的测试，让系统在持续迭代时也能保持更强的稳定性。

  • 异步质量审核支持抽样、全量、关闭三种模式，并接入自动 retry。
  • 新增 Stage H manifest builder 和历史审计工具链，支持结构化核验。
  • 新增 contract、prompt pipeline、rule resolver、worker、integration 等测试。
