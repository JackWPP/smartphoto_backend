详情页预览派生 + 只读预览接口
AI 生图不变，后处理自动派生低分辨率水印预览
P0

详情页仍只调一次 AI生成全分辨率图片（1792x768）。生成完成后 pipeline 自动执行后处理：PIL 将每张 panel 缩小至 800px 宽 + 嵌入半透明对角线水印，存入 session 预览字段。前端可通过只读接口获取低分辨率水印版供预览，付费后通过原 results 接口获取无水印高清版。

新增 API：

方法路径说明
GET /sessions/{id}/detail-pages/preview 只读返回预览面板列表（低分辨率 + 水印），不触发生成

关键实现：

  • derive_detail_previews() — 在 execute_detail_generation_flow 拼图完成后调用，从已渲染的 panel bytes 派生预览
  • apply_watermark() — PIL 绘制对角线半透明 "PREVIEW" 文字，水印嵌入像素不可通过 DevTools 去掉
  • 预览图以 storage.save_generated_image() 持久化，URL 写入 session.detail_preview_image_urls
  • 新增配置项 DETAIL_PREVIEW_WIDTH = 800（对应前端 max_width=400，2x 渲染）

验收标准
测试验证要点
  1. 上传区：连续上传 3 张不同图片，3 张图片均正确显示预览，无覆盖或丢失
  2. 批量上传：使用批量上传接口一次传 3 张图，3 条记录全部创建
  3. 进度条：生成详情图时，进度从 0 开始，前 5 秒增长不超过 15%，后端返回 progress 和 progress_pct 均可用
  4. 文案编辑：修改长文案后选择"智能重排版"，新图片文字布局正确，无竖排、无溢出背景框
  5. 移动端：在 iPhone 14 Pro / 微信浏览器中，所有底部按钮完整可见，无被安全区遮挡
  6. 详情预览（后端水印）：生成完成后调用 GET /detail-pages/preview，返回带内嵌水印的低分辨率预览图；DevTools 无法去掉水印
  7. 配色一致性：三个付费页面按钮均为蓝绿渐变，价格数字为深色，促销标签为橙红渐变白字
  8. 预览→付费跳转：预览后支付成功，结果页显示无水印高清图，底部显示"一键打包下载"而非"获取高清无水印版"
  9. 预览状态持久化：预览生成后刷新页面，GET /sessions/{id} 返回 detail_preview_generated: true
  10. 预览接口幂等：GET /detail-pages/preview 不触发任何生成任务，仅读取已有预览
